## Evidência aceita

- a candidata 1.1.9c foi aprovada fisicamente pelo mantenedor com água translúcida satisfatória, funcionalidades sem bugs observados e Content Log limpo;
- a implementação promovida mantém a caldeirinha integralmente `opaque` e projeta somente a água por uma entidade mínima `entity_alphablend`;
- `npm run check` passou no HEAD promovido: TypeScript, 75 testes do add-on, nove testes do visualizador, documentação, geração de assets, bundle e validadores estruturais;
- `npm run package` reconstruiu o artefato byte a byte com o mesmo tamanho e SHA-256 acima;
- Minecraft Creator Tools aprovou o pacote com os onze avisos offline conhecidos, zero aviso inesperado, zero Error e zero Failure;
- binding, geometry `1.16.0`, poses, animações, seis pulsos, estado finito, IDs públicos, UUIDs, block states, snapshots e contratos de concorrência permaneceram invariantes.

## Aceites e limites

O mantenedor promoveu a 1.1.9 como baseline estável com base na evidência acima. O relatório não declara como executadas medições que não foram registradas:

- comparação de upgrade direto numa cópia persistente da 1.1.7;
- profiler com 1, 16, 64 e 256 caldeirinhas não vazias.

Esses dois itens deixam de bloquear a identidade da release e passam a monitoramento pós-release obrigatório. Qualquer perda de estado, órfão, duplicata ou regressão mensurável reabre a linha como correção incremental, sem alterar silenciosamente o artefato assinado.
