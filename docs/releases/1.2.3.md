# Release 1.2.3 — Localized pack identity and reliable distribution

**Technical release promotion on 2026-08-11.** Version 1.2.3 fixes the public Behavior Pack and Resource Pack identity shown by Minecraft, makes the selected audio-source history self-contained, and consolidates deterministic packaging and transactional local installation. Runtime media, gameplay, and persistent-world contracts remain unchanged.

- Artifact: `dist/releases/Aspergillum-1.2.3.mcaddon` (`3,105,394` bytes).

## Public pack identity

Both manifests now use the Bedrock-standard local keys `pack.name` and `pack.description`. Each pack resolves those keys within its own language scope, preventing the raw legacy `pack.aspergillum.*` tokens from appearing in Minecraft.

The structured authority is `assets-src/branding/pack-identity.json`. It defines concise, pack-specific names and descriptions for `pt_BR` and `en_US`. Validators compare the authority, both manifests, both `languages.json` files, and all four `.lang` files exactly; duplicate, missing, stale, or legacy entries fail the build.

The approved cover and both 256 px pack icons are carried forward byte-for-byte. `assets-src/branding/cover-manifest.json` retains 1.2.1 as the render source and records 1.2.3 only as the current publication.

## Self-contained audio provenance

The 48 selected source files now live under a provider-neutral `assets-src/audio/raw/selected/` tree. Recipes, inventory, provenance, and preparation tooling reference that owned selection directly. Obsolete provider-specific metadata and helper scripts were removed.

This is a provenance and repository-organization correction. The selected source bytes, processed masters, 48 distributed mono 48 kHz Vorbis files, playback recipes, runtime paths, and media hashes remain unchanged.

## Packaging and local installation

Official and diagnostic packagers now share one deterministic ZIP implementation with sorted entries and fixed timestamps. The release registry reserves labels and Bedrock version triples, while generated descriptors and the artifact catalog bind each package to its identity, hash, size, and source provenance. Existing bytes cannot be silently overwritten under the same label.

The local Add-On manager inventories Bedrock installations, plans changes before applying them, caches extraction by SHA-256, serializes mutations with a lock, and rolls back failed transactions. Shared-world dependencies are protected, and the legacy sync commands delegate to the same implementation so installation behavior no longer diverges between entry points.

## Compatibility guarantees

This release preserves the Behavior Pack and Resource Pack UUIDs, module UUIDs, namespace, public item/block/entity identifiers, block states and values, cosmetic indices `0..15`, geometry identifiers, the `1.16.0` geometry format, `aspergillum_bound`, `q.item_slot_to_bone_name(context.item_slot)`, first- and third-person poses, animations, VFX trajectories, audio payloads, finite charges, water encoding, action sessions, locks, docked snapshots, and persistence.

The server remains authoritative for gameplay and state. Version 1.2.3 changes public metadata and production tooling only.
